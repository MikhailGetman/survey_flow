## Порядок

1. Прочитай `PM_BRIEF.md`.
2. Скинь в группу `README_TEAM.md`.
3. Раздай ZIP из `packages/`.
4. Собери GitHub Projects по `GITHUB_PROJECTS_SETUP.md`.
5. Импортируй GanttProject по `GANTT_PROJECT_IMPORT.md`.
6. Покажи преподавателю по `DEMO_WITHOUT_AI.md`.
