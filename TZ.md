# **2\. Назначение и цели**

SurveyFlow предназначен для быстрого создания онлайн-опросов, распространения публичной ссылки, сбора ответов и анализа результатов в реальном времени. Продукт ориентирован на преподавателей, HR-специалистов, маркетологов и руководителей проектов.

Цель — до 20.12.2026 разработать, протестировать и ввести в опытную эксплуатацию веб\-приложение с пятью типами вопросов, live-статистикой с задержкой не более 3 секунд и экспортом отчётов в PDF/SPSS. Критерии успеха: 0 критических дефектов, до 500 одновременных подключений, равномерная нагрузка ролей по 72 часа.

# **4\. Функциональные требования**

Функциональные требования сгруппированы по шести модулям. Для каждого требования указан проверяемый критерий приёмки.

| ID | Модуль | Функции | Критерий приёмки |
| :---: | ----- | ----- | :---: |
| FR-01 | Авторизация и профиль | Регистрация и вход по email/паролю, восстановление пароля, смена имени и пароля, аутентификация | Пользователь регистрируется, входит, восстанавливает пароль и меняет профиль; пароль хранится в виде хеша |
| FR-02 | Личный кабинет | Вкладки «Мои опросы», «Пройденные опросы», «Управление»; поиск, фильтр по статусу, пагинация, удаление | Список опросов отображается, фильтруется, удаляется; чужие опросы недоступны |

# **6\. Архитектура и стек**

Приложение построено по клиент-серверной архитектуре. Frontend — SPA на Vue.js, backend — REST API на Node.js/Express.js, real-time — Socket.IO, хранение — MariaDB. Экспорт PDF реализуется через PDFKit, CSV — стандартными средствами. Код хранится в Git, сборка и тесты запускаются в CI.

| Компонент | Технологии |
| :---: | ----- |
| Frontend | Vue.js, TypeScript, Pinia |
| Backend | Node.js, Express.js, Socket.IO |
| База данных | MariaDB 10.6+, InnoDB, 6 связанных таблиц |
| Экспорт | PDFKit, CSV (UTF-8 BOM) для SPSS |
| Инфраструктура | Git, CI/CD, тестовый сервер |

# **7\. Модель данных и API**

База данных содержит шесть таблиц: users, surveys, questions, question\_options, responses, response\_details. Связи построены через внешние ключи; удаление опроса каскадно удаляет вопросы и ответы. API для авторизации, опросов, прохождения, статистики и экспорта.

| Группа | Эндпоинты |
| :---: | ----- |
| Авторизация | POST /auth/register, POST /auth/login, POST /auth/forgot-password, POST /auth/reset-password, GET/PUT /auth/profile |
| Опросы | GET /surveys, POST /surveys, GET /surveys/:id, PUT /surveys/:id, DELETE /surveys/:id |
| Прохождение | GET /public/surveys/:link, POST /public/surveys/:link/responses |
| Статистика | GET /surveys/:id/stats, Socket.IO events |
| Экспорт | GET /surveys/:id/export/pdf, GET /surveys/:id/export/csv |
